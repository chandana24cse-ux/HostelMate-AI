# HostelMate-AI
HostelMate AI is an AI-powered web app that helps students find hostel rules, facilities, and procedures. Users can upload a PDF handbook and ask questions to get relevant answers using the Groq API. Features include source-page references, chat history, quick questions, and voice input for easy access to hostel information.
## Features
- AI-powered hostel handbook question answering
- PDF upload and source-page references
- Chat history and quick questions
- Voice input
